## Avaliação

O mesmo tradutor assina, pela mesma editora, *Ele que o abismo viu: Epopeia
de Gilgámesh* (2017, ISBN 9788551302835, 336 p.), que é a edição ACADÊMICA,
com notas. Observação, não veredito. Essa edição foi registrada em 23/09/2026,
a pedido do Mathews, como `pub--autentica--ele-que-o-abismo-viu--2017`.

A diferença entre as duas não é só de aparato, e isso ficou verificado em
23/09/2026: esta é uma **segunda versão do texto**, em que o tradutor preencheu
parte das lacunas do poema para obter leitura fluente. Para uma biblioteca que
lê Gilgámesh como fonte, as lacunas são dado, não defeito — mas isto é
observação de fato, não veredito.

Nenhum veredito foi emitido para esta publicação. O §F é um procedimento
ordenado — portão textual, portão físico, faixas de mérito, e só então
idioma — e ele não foi percorrido: os candidatos não foram enumerados antes
de julgar, como o §E.2 passo 4 exige. `verdict: unassessed` é o estado
correto, não uma omissão.
